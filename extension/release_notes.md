## 🚀 ytb2bili Extension v1.0.6

### ✨ 功能特性
- 🎬 支持 YouTube 和 Bilibili 视频信息保存
- 📝 自动获取视频字幕和元数据
- 🔄 实时同步到后端服务
- 🎯 智能视频检测和处理

### 📦 安装包说明
- **Chrome 版本**: 兼容 Chromium 内核浏览器 (Chrome, Edge, 等)
- **Firefox 版本**: 专为 Firefox 浏览器优化

### 🛠 安装方法

#### Chrome/Edge 安装
1. 下载 `ytb2bili-extension-*-chrome.zip`
2. 解压缩文件
3. 打开浏览器扩展管理页面
4. 启用"开发者模式"
5. 点击"加载已解压的扩展程序"，选择解压后的文件夹

#### Firefox 安装
1. 下载 `ytb2bili-extension-*-firefox.zip`
2. 打开 Firefox，访问 `about:debugging`
3. 点击"此 Firefox"
4. 点击"临时载入附加组件"
5. 选择下载的 zip 文件
